# GitHubの説明・連携マニュアル

## GitHubとは

GitHubは、サイトのプログラムや変更履歴をインターネット上で安全に保管するサービスです。

このサイトでは、次のGitHubリポジトリにデータを保存しています。

[sukeaki-kmg/kmg-weather](https://github.com/sukeaki-kmg/kmg-weather)

## よく使う言葉

- **リポジトリ**：サイトのファイルを保管する場所
- **コミット**：変更内容に名前を付けて記録すること
- **Push（プッシュ）**：記録した変更をGitHubへ送ること
- **main（メイン）**：本番用として使用する中心のデータ
- **デプロイ**：変更したサイトをインターネット上に公開すること

## 更新から公開までの流れ

1. パソコン上のローカル環境でサイトを修正する
2. ローカル画面で表示や動作を確認する
3. 変更内容をコミットする
4. GitHubの `main` へPushする
5. 公開サービスへ新しいバージョンを登録する
6. 本番サイトへデプロイする
7. 公開URLで最終確認する

```text
ローカルで修正
    ↓
コミット
    ↓
GitHubのmainへPush
    ↓
本番サイトへデプロイ
    ↓
公開URLで確認
```

## 公開後の確認項目

- 公開URLが正常に開くか
- PCとスマートフォンの両方で崩れていないか
- 現在地・地点検索・天気データが動くか
- 雨雲レーダーが選択地点を表示しているか
- 警報・注意報が表示されるか
- GitHubの `main` に最新コミットがあるか

## 注意事項

- 本番公開前に、必ずローカルで表示を確認します。
- APIキーやパスワードなどの秘密情報はGitHubへ保存しません。
- 不具合が出た場合に戻せるよう、変更内容ごとにコミットします。
- `main` へPushするときは、対象の変更が完成していることを確認します。
